Gates and limits

The mode is set by how reversible the mistake is, not by trust in the model. Reversible runs on its own, financial within a limit, irreversible needs approval. No answer within the deadline: the task is dropped and reported.

Two outcomes, never a third

The entire shape of this route exists for a single property: that a run cannot end any other way than these two.

Outcome 1

It failed and you know. The process stopped with a report that reached a person — not just a log line.

Outcome 2

It went well. The result matches the specification and leaves a traceable record.

The third outcome — “it did something nobody asked for” — has nowhere to arise on this route. The model never holds an irreversible action in its hand. It only ever describes what it sees; the decision and the execution sit in code and in the gate.

Across the whole route

Kill switch — one action that stops the run on any leg. It must be tested, not theoretical. Crash reports go to a person, not to a log. Agent silence must be distinguishable from “there was nothing to do” — otherwise a dead agent looks exactly like a quiet day. The log records decisions, not just results: a month later there is no other way to find out why this particular process ran.

Where it breaks in practice

Three defects found by auditing a running agent. Each sits on a different leg of the route — and all three passed the automated tests.

Acrosskill switch

The kill switch did not cut the route

Stop closed the run record, but no leg ever read a stop flag. Processing carried on and kept sending — there was simply no record of it. The function returned the right value; the system still did not do what it promised.

Outcome 1reporting

The “it failed” outcome was invisible

Messages were sent only on findings. “Found nothing” and “crashed” looked identical from outside — silence. An agent someone relies on could have been dead for a week and it would have looked like an empty market.

Trustboundary

Foreign text crossed the boundary unwrapped

Text written by unknown people entered the model as an instruction rather than as data. A sentence saying “ignore previous instructions” had nothing to stop it. The damage was limited only because the model was allowed to return a bare number — which is luck from the design, not a defence.
